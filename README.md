# ЧЁРТ AI

Локальная панель управления и backend для проекта Chert-ai1.

## Возможности backend

- HTTP API для статуса сервера и бота.
- Запуск и остановка процесса-заготовки бота.
- Сохранение настроек в `data/settings.json`.
- Журнал действий и ошибок в `data/audit.jsonl`.
- Ограничение частоты запросов и проверка размера JSON.
- Проверка доступности публичной страницы Galaxy of Dating.

## Запуск

Требуется Node.js 18 или новее.

```bash
npm start
```

Откройте http://127.0.0.1:8787

Проверка синтаксиса:

```bash
npm run check
```

## API

- `GET /api/health` — проверка backend.
- `GET /api/status` — состояние backend, бота и Galaxy.
- `GET /api/settings` и `PUT /api/settings` — настройки.
- `POST /api/bot/start` и `POST /api/bot/stop` — управление ботом-заготовкой.
- `POST /api/galaxy/check` — запрос публичной страницы Galaxy без входа в аккаунт.
- `GET /api/logs?limit=100` — журнал.

Backend по умолчанию слушает только `127.0.0.1`. Для удалённого размещения обязательно задайте `CHERT_API_TOKEN` и используйте HTTPS reverse proxy. Не выставляйте сервер в интернет без токена.

## Текущие ограничения Galaxy

Интеграция намеренно ограничена проверкой публичной страницы. Она не авторизуется, не читает cookies/localStorage, не получает профиль и не читает/отправляет сообщения. Публичная страница может быть доступна даже тогда, когда игровой сервис временно недоступен.

Для чтения данных аккаунта и сообщений нужен поддерживаемый интерфейс Mobstudio либо отдельное разрешение и безопасный механизм, который не требует передавать пароль или извлекать сессионные секреты. Настройки мониторинга и автоответов пока только сохраняются и не выполняют игровые действия.

## Хранение данных

Рабочие настройки и журнал создаются в каталоге `data/`, который исключён из Git. Пароли и сессионные данные Galaxy не запрашиваются и не сохраняются.
