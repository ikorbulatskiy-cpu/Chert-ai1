# ЧЁРТ AI

Backend и веб-панель проекта Chert-ai1 с ручным браузерным мостом для Galaxy of Dating.

## Возможности

- HTTP API статуса и настроек.
- Запуск и остановка отдельного worker-процесса (пока только heartbeat).
- Журнал действий и ошибок в \`data/audit.jsonl\`.
- Ограничение частоты запросов и размера JSON.
- Проверка доступности публичной страницы Galaxy без входа в аккаунт.
- Ручной импорт текста, который пользователь сам выделил на открытой странице Galaxy.
- Генерация черновика ответа через OpenAI Responses API при наличии серверного `OPENAI_API_KEY`.

## Локальный запуск

Требуется Node.js 20 или новее.

\`\`\`bash
CHERT_HOST=127.0.0.1 npm start
\`\`\`

Откройте http://127.0.0.1:8787. Для локального режима API доступен с loopback без токена.

## Развёртывание на Render

Создайте Web Service из репозитория \`ikorbulatskiy-cpu/Chert-ai1\`.

- Runtime: Node
- Build command: \`npm install\`
- Start command: \`npm start\`
- Environment: \`CHERT_HOST=0.0.0.0\`
- Environment: \`CHERT_API_TOKEN\` = случайный секрет не короче 32 символов (лучше 48–64 случайных символа).
- Node version: 20 или новее.

Render автоматически предоставляет \`PORT\`. Не задавайте его вручную. Не помещайте токен в Git, README, frontend или URL. Вызовы защищённых API должны отправлять заголовок \`Authorization: Bearer <CHERT_API_TOKEN>\`. Публичный \`GET /api/health\` не требует токена.

При внешнем bind приложение откажется запускаться, если токен отсутствует или короче 32 символов. Используйте HTTPS URL Render.

**Важно про бесплатный тариф:** сервис может засыпать при бездействии. Локальные файлы бесплатного сервиса не являются надёжным постоянным хранилищем. Для сохранения настроек, журнала и импортов между перезапусками подключите постоянное хранилище/БД или тариф с диском.

## Подключение Galaxy через Safari на iPhone

Поддерживается пользовательский импорт выделенного текста. Это не официальная интеграция Mobstudio и не автоматическое чтение чата.

1. Открой панель Chert AI и подключи API-токен.
2. В блоке «Подключение Galaxy» нажми «Скопировать код закладки».
3. В Safari добавь любую страницу в закладки, затем открой закладки и нажми «Изменить».
4. Открой созданную закладку и замени её адрес целиком кодом из панели, начиная с `javascript:`.
5. Открой `https://galaxy.mobstudio.ru/web/` и войди обычным способом.
6. Выдели видимый текст сообщений и запусти закладку из меню Safari.
7. Введи API-токен в запросе. Он используется только для этого запроса и не записывается в закладку.
8. Вернись в Chert AI, обнови импорты и нажми «Обработать новый импорт».

Закладка отправляет только текст текущего выделения и URL открытой страницы. Она не читает cookies, хранилища браузера или скрытые данные.

## Galaxy bridge API

- \`POST /api/galaxy/import\` — принять выделенный пользователем текст. Требует Bearer-токен и точный Origin \`https://galaxy.mobstudio.ru\`.
- \`GET /api/galaxy/imports?limit=20\` — прочитать последние импорты; требует Bearer-токен.
- \`POST /api/galaxy/check\` — проверить публичную страницу.
- \`GET /api/status\` — статус.
- \`GET /api/settings\`, \`PUT /api/settings\` — настройки.
- \`POST /api/bot/start\`, \`POST /api/bot/stop\` — управление worker-заготовкой.
- \`GET /api/logs?limit=100\` — журнал.

Все API-маршруты, кроме health, требуют Bearer-токен при удалённом размещении. CORS для импорта разрешён только с официального origin Galaxy.

## Ограничения

Мост не выполняет автоматический вход, не извлекает сессионные данные, не ищет скрытые API и не обходит антибот-защиту. Он импортирует только выделенный пользователем текст. Автоматическое чтение всех сообщений, отправка сообщений и автоответы пока не реализованы. Для таких функций требуется отдельная проверка того, что сайт предоставляет разрешённый и устойчивый интерфейс.

## Проверки

\`\`\`bash
npm run check
npm test
\`\`\`

Smoke test проверяет health, авторизацию API, настройки, worker и журнал. Он не доказывает совместимость с реальным игровым аккаунтом.

## Данные

Настройки, журнал и импортированный текст находятся в \`data/\`, исключённом из Git. Для тестов можно переопределить каталог через \`CHERT_DATA_DIR\`. Импортированный текст хранится на backend, поэтому передавай только то, что действительно хочешь там сохранить.
